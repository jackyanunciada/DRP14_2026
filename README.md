# 🥖 Lá Casa dos Pães — Sistema de Pedidos Online

## 📌 Sobre o projeto

Aplicação web desenvolvida com Flask que simula o fluxo de pedidos de uma padaria, permitindo que clientes realizem pedidos e acompanhem seu status, enquanto o administrador gerencia e atualiza os pedidos em tempo real.

O projeto foi desenvolvido com foco na aplicação prática de conceitos de desenvolvimento web full-stack, autenticação de usuários, banco de dados e integração entre backend e interface web.

## ⚙️ Funcionalidades

### 👤 Área do Cliente

✔ Cadastro e autenticação de usuários  
✔ Login e logout  
✔ Visualização do cardápio com imagens  
✔ Criação de pedidos com seleção de produtos e quantidade  
✔ Visualização dos pedidos realizados  
✔ Acompanhamento do status do pedido  
✔ Área de perfil  
✔ FAQ integrado ao sistema  
✔ Sistema de notificações  

---

### 🏪 Área Administrativa

✔ Visualização de todos os pedidos  
✔ Atualização do status dos pedidos  
✔ Gerenciamento do fluxo dos pedidos  
✔ Controle administrativo centralizado

## 🚀 Como executar localmente

Clone o projeto:

```bash
git clone https://github.com/jackyanunciada/DRP14_2026.git
```

Entre na pasta:

```bash
cd DRP14_2026
```

Instale as dependências:

```bash
pip install flask
```

Execute:

```bash
python app.py
```

Abra no navegador:

```bash
http://127.0.0.1:5000
```
